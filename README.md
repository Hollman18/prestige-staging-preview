# Prestige Home Staging — compiled preview

Build output only, served from GitHub Pages while the domain is set up. No source code here; the
project lives in the private repository `Hollman18/prestige-staging-web`.

The preview sends `noindex` and disallows crawlers, so it cannot compete with the live domain. The
quote form validates exactly as it does in production but cannot deliver an enquiry, because Pages
has no server; it says so rather than pretending a message was sent.
